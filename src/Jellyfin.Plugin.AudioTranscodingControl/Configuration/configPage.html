Diagnostics & Logging

Logs: Jellyfin Dashboard → Logs, in the server's configured log directory. Changes apply to the next request without a restart. If the server filters Debug/Trace, these diagnostics use native Information entries labeled with their original level. Stricter global filters can still suppress messages; no global logging file is changed.

No tokens, full stream URLs, media paths or raw device/user identifiers are logged. Stream offers do not prove client use or actual FFmpeg output.
